# Gemma Edu — Landing page React

Landing page en React JS et CSS pur, organisée sur une seule page.

## Changements de cette version

- largeur générale réduite et contenu recentré ;
- titre, boutons, carte QR et téléphones plus compacts ;
- section Technologies affichée sous forme de parcours horizontal, sans cartes ;
- logos React, CSS, Dart, Flutter, FastAPI, SQLite et Gemma chargés depuis `cdn.simpleicons.org` ;
- mise en page responsive pour ordinateur, tablette et mobile ;
- solution de repli avec initiale si un logo externe ne se charge pas.

## Lancer le projet

```bash
npm install
npm run dev
```

Les logos technologiques utilisent une connexion Internet. Les images principales de la landing page restent dans `public/assets`.
